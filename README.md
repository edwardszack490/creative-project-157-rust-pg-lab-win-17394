## About Rust PostgreSQL Lab

Rust PostgreSQL Lab is an interactive web lab focused on PostgreSQL database visualization and rewrite exploration. It is built for users who want a clearer way to inspect database behavior, experiment with multi-mode views, and work through structured database scenarios without leaving the browser.

The project combines Rust and PostgreSQL concepts with an interactive presentation layer, making it useful for learning, demonstrations, and workflow testing. Its lab-style layout is designed to support step-by-step exploration, so users can move between different visualization modes while keeping the database context easy to follow.
